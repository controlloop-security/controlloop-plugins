# Security Policy

These plugins tell a coding agent how to run the ControlLoop CLI. A report
about the analysis itself belongs to the
[CLI repository](https://github.com/controlloop-security/controlloop/security).
Report here anything that makes a plugin do more than it says: edit
configuration, send data, run something at session start, or run a command
the user did not ask for.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Include:

- A concise description and the affected host and plugin.
- Reproduction steps using synthetic data.
- Expected and observed behavior.
- Security or privacy impact.

Do not include real credentials, customer data, proprietary repositories,
private prompts, or other people's personal data.

## Supported versions

The latest release on `main` receives fixes.
